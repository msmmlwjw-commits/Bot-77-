# 🎵 بوت تحميل السوشيال ميديا | Social Media Download Bot

بوت متقدم لتحميل الفيديوهات من منصات التواصل الاجتماعي مع دعم استنساخ حسابات TikTok كاملة وإدارة متقدمة.

## ✨ الميزات الرئيسية

### 📥 التحميل العادي
- ✅ دعم تحميل من TikTok, Instagram, Facebook, Snapchat, Pinterest, Kwai
- ✅ تحميل دفعي (multiple videos)
- ✅ أفضل جودة متاحة
- ✅ معالجة الصوت تلقائياً (إصلاح الفيديوهات بدون صوت)

### 🚀 استنساخ TikTok
- ✅ تحميل 20 فيديو في المرة (مع خيار التكملة)
- ✅ استنساخ كامل للحساب
- ✅ جلب من آخر نقطة وصول إليها
- ✅ إدارة جلسات منفصلة لكل مستخدم
- ✅ Streaming مباشر للفيديوهات

### ⚙️ لوحة الإدارة
- ✅ تعديل رسالة الترحيب (بدون حذف المتغيرات)
- ✅ إدارة القنوات (عادي + استنساخ)
- ✅ تحقق تلقائي من صلاحيات البوت في القناة
- ✅ إذاعة متقدمة (نص, صور, فيديو, صوت, ملفات, ملصقات)
- ✅ إحصائيات شاملة مع حفظ في قاعدة البيانات

### 📊 الإحصائيات والتقارير
- ✅ إجمالي المستخدمين
- ✅ المستخدمون النشطون
- ✅ المحظورون
- ✅ عدد مرات الاستخدام (عادي + استنساخ)
- ✅ إجمالي الفيديوهات المحملة
- ✅ سجل الإذاعات
- ✅ أول ملخص وآخر دخول لكل مستخدم

### 🎯 الميزات الإضافية
- ✅ قاعدة بيانات SQLite (دائمة)
- ✅ نظام معياري (Modular)
- ✅ معالجة الأخطاء المتقدمة

## 🚀 التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone https://github.com/ohljbk2024-ui/333.git
cd 333
```

### 2. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 3. تثبيت FFmpeg (اختياري لإصلاح الصوت)

**على Windows:**
```bash
choco install ffmpeg
```

**على macOS:**
```bash
brew install ffmpeg
```

**على Linux:**
```bash
sudo apt-get install ffmpeg
```

### 4. إعداد متغيرات البيئة

أنشئ ملف `.env`:
```bash
TELEGRAM_BOT_TOKEN=your_bot_token_here
ADMIN_ID=your_admin_id_here
```

### 5. تشغيل البوت
```bash
python bot.py
```

## 📖 دليل الاستخدام

### للمستخدمين العاديين

#### تحميل فيديو واحد
1. أرسل رابط الفيديو للبوت
2. سيتم التحميل والإرسال تلقائياً

#### تحميل دفعة من الفيديوهات
1. اضغط على 📥 "تحميل دفعة واحدة"
2. أرسل جميع الروابط في رسالة واحدة
3. سيتم تحميلها جميعاً

#### استنساخ حساب TikTok
1. اضغط على 🚀 "استنساخ TikTok"
2. أرسل أحد الخيارات:
   - `https://www.tiktok.com/@username`
   - `@username`
   - `username`
3. اختر العملية:
   - 📥 جلب 20 فيديو
   - 🚀 استنساخ كامل
   - 🔄 تغيير الحساب

### للمسؤولين

#### دخول لوحة الإدارة
1. اضغط على ⚙️ "إدارة البوت"

#### تعديل رسالة الترحيب
1. اختر ✏️ "تعديل رسالة الترحيب"
2. أرسل الرسالة الجديدة
3. يمكن استخدام `{name}` لاسم المستخدم

#### إدارة القنوات
1. اختر القناة (عادي أو استنساخ)
2. أرسل رابط القناة أو `@اسم_القناة`
3. سيتم التحقق من صلاحيات البوت تلقائياً

#### الإذاعة
1. اختر 📡 "إذاعة لجميع المستخدمين"
2. اختر نوع المحتوى
3. أرسل المحتوى
4. أكد الإرسال
5. سيتم عرض تقرير النتائج

#### عرض الإحصائيات
1. اختر 📊 "الإحصائيات"
2. سيتم عرض التقرير الكامل

## 📝 ملاحظات مهمة

### إصلاح الصوت
- البوت يكتشف تلقائياً الفيديوهات بدون صوت
- يحاول إصلاحها باستخدام FFmpeg
- إذا فشل الإصلاح، يرسل الفيديو كما هو

### حد آمن للتحميل
- كل فيديو يتم حذفه من السيرفر بعد الإرسال
- استخدم Streaming للفيديوهات الكبيرة

### الأمان
- فقط المسؤول يمكنه الوصول للوحة الإدارة
- جميع البيانات محفوظة في قاعدة البيانات
- عدم تخزين التوكنات في الكود

## 🐛 استكشاف الأخطاء

### الفيديو لا يحمّل
- تحقق من صحة الرابط
- جرب رابط آخر
- تحقق من الاتصال

### المشكلات مع FFmpeg
- تأكد من تثبيت FFmpeg بشكل صحيح
- `ffmpeg -version` للتحقق

### البوت لا يرسل للقناة
- تأكد من أن البوت مشرف في القناة
- تأكد من صلاحياته (الإرسال، التثبيت)

### المشكلات مع قاعدة البيانات
- احذف `bot_database.db`
- سيتم إعادة إنشاؤها تلقائياً
